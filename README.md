# Progressive Delivery Strategies

A reference on **progressive delivery** (canary, blue/green, and related) strategies
for releasing software with reduced risk.

## What's inside

- Notes describing progressive delivery patterns and when to apply each.
- Ties into the Argo Rollouts demos in the sibling `Argo-Rollouts` and
  `K8s-Voting-App` repositories.

## What you'll learn

- The difference between blue/green, canary, and other progressive strategies.
- How to shift traffic gradually and roll back on failure.
- How Argo Rollouts implements these strategies.

## Tools covered

- Argo Rollouts, deployment strategies, Kubernetes.

## How to use

Read the notes for the conceptual model, then experiment with the runnable demos in
`Argo-Rollouts` (Blue/Green and Canary) to see each strategy in action.
